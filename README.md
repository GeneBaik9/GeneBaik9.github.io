# GeneBaik9.github.io

정적 HTML·CSS·JavaScript로 만든 반응형 개인 프로페셔널 웹사이트입니다.

## 주요 구성

- 다크 테마 기반 반응형 레이아웃
- About, Work, Games 내비게이션
- 키보드·모바일 터치 지렁이 게임을 확장할 Games 영역
- GitHub Pages 정적 배포

## 실행

별도 빌드 과정 없이 정적 파일을 웹 서버로 제공하면 됩니다.

```text
index.html
styles.css
script.js
```
